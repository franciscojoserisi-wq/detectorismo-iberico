DETECTORISMO IBÉRICO — VERSIÓN 2

Esta versión incluye:
- Portada/cabecera gráfica.
- Catálogo ilimitado en estructura.
- Formulario de aportaciones.
- Panel de administración de demostración.
- Exportación JSON.
- Protección pública de localizaciones exactas por diseño.

IMPORTANTE: la autenticación y almacenamiento actuales son locales al navegador y NO son seguridad real.
Para publicar y recibir aportaciones de usuarios de Internet se debe conectar el proyecto a una base de datos y autenticación segura (por ejemplo Supabase/Firebase) o a un backend propio.

Para probarla: abrir index.html.
Panel: admin/index.html
